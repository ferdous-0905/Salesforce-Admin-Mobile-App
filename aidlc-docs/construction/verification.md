# Verification matrix

- Pure rules: grading, progress, backup, resource mapping and navigation regression tests.
- Build: strict TypeScript, AI-DLC structure, Expo compatibility and Android/iOS bundle export.
- Native: rebuild/install after WebView or icon changes; preserve the existing learner profile.
- UI: tab round trips with selected answers, submitted feedback, selected explanation section, scroll offsets and unsaved settings input.
- Learning media: mapped question screenshot preview/enlargement and YouTube player load; explicit empty states for unmapped questions.
- Accessibility: labelled icons, touch target sizes, text scaling and Reduce Motion behavior; real device/screen-reader results must be recorded separately.

Actual results belong in the active intent's evidence file. A passing structural validator does not prove these interactions work.
