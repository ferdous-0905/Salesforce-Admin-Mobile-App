# App icon asset

Generated with the built-in image generation tool, then resized/padded for native icon dimensions. Source: `assets/app-icon.png`; adaptive foreground: `assets/adaptive-icon.png`. Both are 1024×1024 opaque PNGs. References are configured in app.json; no external image URL is required.

Final prompt: Create a polished square mobile app icon for an independent mindful administrator quiz app. An open ivory book whose pages form a gentle leaf/sprout with a small golden learning spark, centered on deep evergreen teal. Sculptural paper illustration, calm joyful learning aesthetic, legible at small sizes, generous safe padding, no text, no letters, no Salesforce logo, no watermark, full-bleed opaque square background.

The source generated image remains intact outside the workspace. Project assets are self-contained copies.
